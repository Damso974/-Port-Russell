Documentation API - Port Russell

Accueil Tableau de bord

1. Vue d'ensemble

L'API REST du Port de plaisance Russell permet de gérer les utilisateurs, les catways et les réservations du port.

L'application utilise Node.js, Express, MongoDB et Mongoose.

Certaines routes nécessitent une authentification. Lors de la connexion, un token JWT est enregistré dans un cookie HTTP.

2. Tutoriel

Créer un utilisateur

Requête :

POST /users
Content-Type: application/json

Corps de la requête :

{
    "name": "Utilisateur Test",
    "email": "test@russell.fr",
    "password": "Test@1234"
}

Se connecter

Requête :

POST /users/login
Content-Type: application/json

Corps de la requête :

{
    "email": "test@russell.fr",
    "password": "Test@1234"
}

Après une connexion réussie, le serveur enregistre le token d'authentification dans un cookie.

Ce cookie permet ensuite d'accéder aux routes protégées de l'API.

3. Routes de l'API

Utilisateurs

Méthode Route Description Authentification
POST /users Créer un utilisateur Non
POST /users/login Connexion d'un utilisateur Non
GET /users Afficher les utilisateurs Oui
PATCH /users/:id Modifier un utilisateur Oui
DELETE /users/:id Supprimer un utilisateur Oui
POST /users/logout Déconnexion Oui

Catways

Méthode Route Description Authentification
GET /catways Afficher tous les catways Oui
GET /catways/:id Afficher un catway Oui
POST /catways Créer un catway Oui
PUT /catways/:id Remplacer complètement un catway Oui
PATCH /catways/:id Modifier partiellement un catway Oui
DELETE /catways/:id Supprimer un catway Oui

Réservations

Méthode Route Description Authentification
GET /reservations Afficher toutes les réservations Oui
GET /catways/:id/reservations Afficher les réservations d'un catway Oui
GET /catways/:id/reservations/:idReservation Afficher une réservation Oui
POST /catways/:id/reservations Créer une réservation Oui
DELETE /catways/:id/reservations/:idReservation Supprimer une réservation Oui

4. Exemples

Créer un catway

POST /catways

{
    "catwayNumber": 36,
    "type": "long",
    "catwayState": "Bon état"
}

Modifier l'état d'un catway

PATCH /catways/36

{
    "catwayState": "Maintenance"
}

Créer une réservation

POST /catways/4/reservations

{
    "clientName": "Jean Dupont",
    "boatName": "Océan",
    "checkIn": "2026-10-10",
    "checkOut": "2026-10-15"
}

Supprimer une réservation

DELETE /catways/4/reservations/:idReservation

5. Glossaire

API
Interface permettant à différentes applications de communiquer entre elles.
REST
Architecture utilisant notamment les méthodes HTTP GET, POST, PUT, PATCH et DELETE.
Catway
Emplacement du port permettant l'amarrage d'un bateau.
JWT
JSON Web Token utilisé pour authentifier un utilisateur.
MongoDB
Base de données NoSQL utilisée par l'application.
Mongoose
Bibliothèque permettant de manipuler MongoDB depuis une application Node.js.
Middleware
Fonction exécutée entre la réception d'une requête et son traitement par le contrôleur.
CRUD
Create, Read, Update et Delete : les quatre opérations principales de gestion des données.
